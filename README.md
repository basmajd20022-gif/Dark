# Telegram Bot (Telethon)

بوت تليجرام مبني بلغة **Python** باستخدام مكتبة **Telethon**، مخصص للتعامل مع الحسابات وإدارة الجلسات والتحكم بالقنوات والمجموعات بشكل آلي.

---

## 🚀 المميزات
* إدارة الجلسات باستخدام `StringSession`.
* التعامل التلقائي مع الأخطاء الشائعة مثل الحظر المؤقت (`FloodWaitError`) أو مشاكل التحقق.
* الانضمام التلقائي للقنوات وتنفيذ المهام الإدارية.

---

## ⚙️ المتطلبات
تأكد من تثبيت المكتبات المطلوبة الموجودة في ملف `requirements.txt`:

pip install -r requirements.txt
